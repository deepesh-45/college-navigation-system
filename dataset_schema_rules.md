# Smart AI Campus Navigation — Dataset Schema & Node Taxonomy Rules

To ensure dataset consistency across all real campus data entry, all nodes, graph edges, and LLM routes MUST adhere to the strict schema specification documented below.

---

## 🏷️ Complete Physical Node Taxonomy (`GraphNode.type`)

Every location or physical point on campus MUST be categorized into one of the following exact types:

| Node Type | Icon & Description | Examples |
| :--- | :--- | :--- |
| `entrance` | 🚪 Building or Campus Entrances / Main Gate | `Main Entrance`, `Library Gate`, `Block A Gate` |
| `junction` | 🔀 Hallway Intersection / Turn Point | `Junction 1`, `Corridor Crossroads`, `T-Junction` |
| `staircase` | 🪜 Stairs linking adjacent floors | `Staircase Floor 1`, `Central Stairs`, `West Stairs` |
| `elevator` | 🛗 Lift / Elevator linking floors | `Main Elevator`, `Block B Lift` |
| `classroom` | 🏫 Lecture Rooms & Classrooms | `Classroom 101`, `Lecture Hall 3` |
| `lab` | 🔬 Specialized Research & Academic Labs | `Data Science Lab`, `AI Lab`, `Physics Lab` |
| `cabin` | 👔 Faculty & Admin Cabins | `Dean Office`, `HOD Cabin`, `Dr. Sharma Cabin` |
| `washroom` | 🚻 Restroom Facilities | `Washroom Floor 1`, `Gents Restroom`, `Ladies Washroom` |
| `watercooler` | 🚰 Drinking Water Stations | `Water Cooler Station F1`, `Water Filter F2` |
| `auditorium` | 🎭 Large Assembly & Event Halls | `Main Auditorium`, `Seminar Hall A` |
| `library` | 📚 Campus Central & Department Libraries | `Central Library`, `Digital Library` |
| `canteen` | ☕ Food Courts & Cafeterias | `Campus Canteen`, `Coffee Shop` |
| `facility` | 🏢 General Campus Facilities | `Accounts Section`, `Reprographics` |

## 📜 Standardized Gemini Step Prompt Format

All step instructions generated by Gemini AI or Dijkstra Graph Pathfinder MUST adhere to the standard prompt format:

```text
"Move straight approx [N] steps and [Action]."
```

### Standard Action Options:
- `turn left`
- `turn right`
- `take stairs up`
- `take stairs down`
- `take elevator`
- `reach destination`

### Examples:
- *"Move straight approx 30 steps and turn right."*
- *"Move straight approx 10 steps and take stairs up."*
- *"Move straight approx 25 steps and turn left."*
- *"Move straight approx 15 steps and reach destination."*

---

## 🪜 Inter-Floor Connector Rules

1. Any `staircase` or `elevator` node marked on Floor $N$ MUST link to the corresponding `staircase` or `elevator` node on Floor $N+1$ or Floor $N-1$.
2. For inter-floor travel, the route MUST first direct the user to the `staircase`/`elevator` node on the current floor, then prompt to climb/descend stairs, then navigate on the target floor to the final destination.
